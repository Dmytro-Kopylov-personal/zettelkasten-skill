# Index

Every note in the vault, one line each. The format is:

```text
- [[202609261430-attention-budget]] — Attention budget is a scarce resource
```

A note that is not listed here is reported as `ZK012`, and so is an entry naming a note
that does not exist. Both directions matter: an index that misses notes stops being a map,
and an index with dead entries sends a reader somewhere that is not there.

Keep it alphabetical by title, not by date. The index is for finding, and nobody remembers
the timestamp of the thing they are looking for.
