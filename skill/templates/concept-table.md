# Concept table

The durable concepts this vault has settled on, and the note that best states each one.
Not every tag belongs here — this is the short list of ideas the vault keeps coming back
to, so that a query can start somewhere better than a full-text search.

| Concept | Note |
|---|---|

One row per concept, in the form:

```text
| attention budget | [[202609261430-attention-budget]] |
```

Update a row when a better note becomes the canonical one. A concept with two candidate
notes is a merge waiting to happen, not a row with two entries.
